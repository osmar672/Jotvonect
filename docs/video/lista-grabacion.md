# Lista de grabación

## Preparación

- [ ] Los dos Pull Requests están integrados en la rama usada para grabar.
- [ ] Los seis módulos aparecen en el orden oficial.
- [ ] La autenticación y el logout funcionan.
- [ ] La consola del navegador está limpia.
- [ ] La API de DummyJSON responde.
- [ ] Los datos de demostración no contienen información personal.

## Audio y entorno

- [ ] Micrófono probado sin eco ni saturación.
- [ ] Notificaciones del sistema desactivadas.
- [ ] Habitación silenciosa.
- [ ] Volumen de voz uniforme.
- [ ] Cursor visible y movimientos lentos.

## Video

- [ ] Resolución mínima de 1920 × 1080.
- [ ] Escala del navegador legible.
- [ ] Duración objetivo entre 7 y 9 minutos.
- [ ] Sin pausas largas ni pantallas privadas.
- [ ] Títulos de pestañas y ventanas adecuados.

## Demostración funcional

- [ ] Login correcto y validación de error.
- [ ] Navegación por los seis módulos.
- [ ] Demostración de GET en cada módulo.
- [ ] Vacantes: POST, PUT, PATCH y DELETE.
- [ ] Empresas: POST, PUT y DELETE.
- [ ] Postulaciones: POST, PATCH y DELETE.
- [ ] Operaciones principales de Candidatos, Entrevistas y Tareas.
- [ ] Mensajes de carga, éxito y error.
- [ ] Confirmación antes de eliminar.
- [ ] Estado local después de cada mutación.
- [ ] Vista de computadora, tablet y teléfono.
- [ ] Navegación mediante teclado.

## Repositorio

- [ ] Ramas visibles.
- [ ] Pull Requests visibles.
- [ ] Commits ordenados por funcionalidad.
- [ ] Contrato y propiedad de archivos explicados.
- [ ] README, pruebas y reporte final mostrados.

## Revisión final

- [ ] Se recortaron errores y tiempos muertos.
- [ ] El audio coincide con la acción mostrada.
- [ ] No aparecen contraseñas personales, tokens ni datos sensibles.
- [ ] El enlace final tiene permisos de visualización.
- [ ] El nombre del archivo y el enlace se anotaron en `enlace-video.md`.
